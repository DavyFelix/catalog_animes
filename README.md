# 🎬 Catálogo de Animes --- Flutter + GraphQL

Aplicação em Flutter que consome a API do AniList via GraphQL, exibindo:

-   Lista de animes
-   Busca em tempo real
-   Favoritos
-   Página de detalhes
-   Trailer (YouTube)
-   Tema claro/escuro
-   Skeleton / Loading

------------------------------------------------------------------------

## 📥 Como baixar o projeto

### 🔹 Opção 1 --- Baixar ZIP

1️⃣ Clique em **Code**\
2️⃣ Clique em **Download ZIP**\
3️⃣ Extraia o arquivo no seu computador

------------------------------------------------------------------------

### 🔹 Opção 2 --- Clonar via Git

``` bash
git clone https://github.com/DavyFelix/catalog_animes.git
```

Depois:

``` bash
cd catalog_animes
```

------------------------------------------------------------------------

## ⚙️ Requisitos

-   Flutter 3.0+
-   Dart 3+
-   Android Studio ou VS Code
-   Emulador ou celular físico

------------------------------------------------------------------------

## 🚀 Rodando o projeto

Instale as dependências:

``` bash
flutter pub get
```

Execute:

``` bash
flutter run
```
